# Raffly

Weekly Telegram Mini App raffle — $1,000 USDT prize pool split among 5 winners ($200 USDT each).

## Quick start

```bash
npm install
cp .env.example .env.local   # fill in Supabase + Telegram keys
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) for local dev, or launch via [@Rafflyapp_bot](https://t.me/Rafflyapp_bot) in Telegram.

See [NOTES.md](./NOTES.md) for architecture, schema, and roadmap.

## Stack

Next.js · TypeScript · Tailwind CSS · Supabase · Vercel · Telegram Mini Apps SDK
